# ClassCtrl - 课堂控制软件 (仿极域架构 · 纯 C / Win32) v1.5.0

参照极域电子教室的架构思路, 用**纯 C + Win32 API**实现的课堂管理演示软件:
**主控端(教师) `Teacher.exe` + 被控端(学生) `Student.exe`** 两个独立程序,
通过 UDP 广播发现 + TCP 控制通道 + UDP 组播屏幕广播 + 子网反向扫描 协同工作。

| | |
|---|---|
| 纯 C, 零第三方库 | 仅依赖 Win32 API, gcc 直接编译, exe 静态链接可直接分发 |
| 透明运行 | 有可见窗口/托盘图标, 无隐藏、无自启、无防杀设计 |
| 密码保护 | 学生端退出与紧急解除均需密码 (默认 `654321`, 源码可改) |

> ⚠️ **仅供学习与课堂教学使用**, 请勿用于任何未授权用途。
> 跨网段/远程场景请确保你对该网络与学生机器拥有管理权限。

---

## 功能

| 功能 | 主控端操作 | 被控端效果 |
|---|---|---|
| 学生列表 | 卡片式双行列表(名称+IP), 状态胶囊: 在线/未连接/已锁定/广播中 | — |
| 广播消息 | 输入文字→"广播消息"(未选中=全体) | 屏幕中央弹出圆角置顶消息卡(15 秒自动关闭) |
| 锁定屏幕 | "锁定屏幕" | 全屏深色画面+锁形卡片, 屏蔽 Alt+Tab/Win/Alt+F4, 看门狗压制任务管理器 |
| 解除锁定 | "解除锁定" | 恢复正常 |
| 屏幕广播 | "开始/停止屏幕广播" | 教师屏幕(半分辨率 RGB555)组播到学生全屏, 静止画面不传 |
| 下发文件 | "下发文件..." | 保存到学生机 `文档\课堂接收文件` |
| 远程桌面控制 | 选中一名学生→"远程桌面" | 实时观看学生屏幕并直接操作其鼠标键盘 |
| 远程终端 | 选中一名学生→"远程终端" | 学生端 `cmd /C` 执行命令并回传输出(GBK 自动转码) |
| 远程关机/重启 | 确认后下发 | 学生机关机/重启 |
| 全屏紧急退出 | — | 隐藏机制: 全屏内 5×F8(3 秒内)→输入密码→解除全屏 |
| 退出被控端 | — | "退出程序"需输入密码 **654321** |

## 快速开始

1. 两端机器运行 `dist\` 里的 `Teacher.exe` 与 `Student.exe`(或自行编译, 见下文)
2. 首次运行在防火墙弹窗中点"允许"(或点教师端"防火墙修复"一键放行)
3. 学生端约 2~3 秒显示"已连接教师端", 教师端列表出现该学生(绿点·在线)
4. 未选中列表行时, 命令作用于**全体在线学生**; Ctrl+点击可多选

## 三条接入路径 (任一打通即上线, 自动去重)

| 路径 | 机制 | 适用场景 |
|---|---|---|
| A. UDP 广播 | 教师三路广播(全局/回环/各网卡子网定向)→学生连 15666 | 正常局域网 |
| B. 子网反向扫描 | 学生监听 TCP 15670, 教师每 10 秒扫描本机各网卡 /24 并主动连入 | 广播被拦/同机沙盒 |
| C. 手动指定 | 学生机 `Student.exe 教师IP`; 教师端"指定学生IP"按钮 | 跨网段/兜底 |

### 跨网段部署 (教师机与学生机不在同一网段)

满足任一即可:

1. **IT 开通网段间路由**(最规范): VLAN 间放行 TCP 15666/15668/15670, 教师端命令行
   `Teacher.exe 192.168.32.0 192.168.33.0` 指定学生网段(可多个), 或学生端 `Student.exe 教师IP` 直连
2. **VPN 虚拟局域网**(推荐): 两端安装 [Tailscale](https://tailscale.com) 或 ZeroTier,
   机器进入同一虚拟网段后**现有代码零改动**直接工作
3. **教师端"指定学生IP"**: 输入学生机 IP 反向拨号(需学生机 15670 可达)

> 跨越你无管理权限的网络边界(如穿透学校网络策略)不属于本软件的设计目标;
> 若确有需求应与网络管理员协调开通路由。

## 网络协议

```
[发现]  Teacher --每3s--> 255.255.255.255:15555 + 127.0.0.1:15555 + 各网卡子网定向广播
        报文: "TEACON|v1|<对应网卡IP>"
        Student --首次---> Teacher:15556  "STULOGIN|主机名"
        Student --每2s---> Teacher:15556  "STUHB|主机名"

[控制]  Student --TCP 长连接--> Teacher:15666, 帧 = [u32 长度][载荷]
        载荷 = "命令头\n" + 可选数据
        教师→学生: LOCK / UNLOCK / MSG|n / DEMO_START / DEMO_STOP /
                   FILE|名|大小 / EXEC|n / RDP_START / RDP_STOP / SHUTDOWN / REBOOT
        学生→教师: HI|主机名 / ACK|命令 / EXECOUT|n

[广播]  Teacher --UDP 组播 239.10.10.10:15667-->
        截屏→缩放 1/2→RGB555→拆 1400B 小片(片头 28B: 魔数/帧序/片号/总片数/帧大小/宽/高)
        学生端重组整帧后 StretchDIBits 全屏渲染, 约 5~6 帧/秒

[远程桌面] TCP 15668 (学生→教师连接, 双向)
        学生→教师: [u32 长度][20B 头: 魔数'RCAP'/帧序/宽/高/大小][RGB555 数据]
        教师→学生: [u32 长度]["M|x|y" / "MD|btn|x|y" / "MU|btn|x|y" / "W|x|y|d" / "K|vk|down" / "X"]
        坐标为 0~65535 归一化值, 与两端分辨率无关

[终端]  教师→学生: EXEC|n + UTF-8 命令 → cmd /C 执行(60 秒看门狗, GBK 输出转 UTF-8)
        学生→教师: EXECOUT|n + UTF-8 输出
```

## 编译

需要 [MinGW-w64](https://winlibs.com/) 的 gcc (或 MSYS2):

```bat
build.bat
```

等效命令:

```bat
gcc -O2 -std=gnu99 -Wall -mwindows -static -o dist\Teacher.exe src\teacher.c ^
    -lws2_32 -lgdi32 -lcomdlg32 -luser32 -lshell32 -ldwmapi -liphlpapi -ladvapi32
gcc -O2 -std=gnu99 -Wall -mwindows -static -o dist\Student.exe src\student.c ^
    -lws2_32 -lgdi32 -luser32 -lshell32 -ldwmapi -ladvapi32
```

## 全屏行为说明

- 锁屏/广播期间: 300ms 周期重夺置顶与前台; **任务管理器看门狗**每 300ms 结束
  Taskmgr.exe(任务管理器经安全桌面启动且自带置顶, 用户态窗口压不住, 只能移除源头)
- 两个隐藏逃生口(界面无提示): 广播画面 **Ctrl+Alt+Q**; 锁屏/广播通用 **5×F8+密码**
- Ctrl+Alt+Del 安全桌面本身无法覆盖, 这是 Windows 系统限制(极域同样如此)

## 已知限制

- 广播未压缩(RGB555, ≈1MB/帧×6fps), 适合百兆以上有线网; 极域用 JPEG/H264 压缩
- 反向扫描只覆盖各网卡 /24 网段; 跨网段请用"指定学生IP"/命令行网段/VPN 组网
- 按键注入基于 VK 虚拟键, 无法注入中文输入法文字; 多显示器只处理主屏
- 锁屏无法屏蔽 Ctrl+Alt+Del 安全桌面本身
- 提权运行的"任务管理器"需被控端同样以管理员运行才能被看门狗结束
- 下发大文件时教师端界面会短暂无响应(单线程顺序发送)
